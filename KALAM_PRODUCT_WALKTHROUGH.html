Section 01

Login & Registration

Kalam provides a clean, mobile-first authentication experience. Coaches and academy owners sign in on the Welcome Back screen using their registered email and password. New users register through a dedicated Registration Form with profile setup and personal details.

Design System

Kalam uses a consistent dark theme (black/dark gray background) with orange (#e94560 / #ff6b35) accents throughout. Key UX patterns include:

Chip-Based Filters

All filter selections use horizontal scrollable chips with orange active state — replacing traditional dropdown menus.

Card-Based Lists

All data is displayed in dark gradient cards with colored left accents, metadata chips, and action bars.

Stats Summary Bars

Compact stat bars with color-coded numbers summarize data at a glance before the detail cards.

Mobile-First Responsive

All screens designed mobile-first with breakpoints for tablets (768px) and desktop (1024px+).
